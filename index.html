    Architecture

    Four layers. None of them can skip the policy engine.

    Every tool call carries a workspace ID and passes through policy checks before it touches a website, an app or your money.

    • Interfaces Dashboard, phone approvals, voice and the emergency stop.
    • Orchestrator Planner, policy engine, checkpointed task queue, verifier.
    • Tools APIs, browser, desktop apps, documents and photos, research.
    • Workspaces Separate data, vault, rules and history per business.
    WorkspacesA · B · C · … N
    ToolsAPI · Browser · Desktop · Docs

    Workspaces

    Each business keeps its own data, logins, rules and history.

    One shared model server, no virtual machine per business. Isolation is enforced in code on every call — try to break it.

    Phone approvals

    When it needs a person, it parks the task and asks you.

    Notifications come from a self-hosted ntfy server on your PC, reached over your own VPN. No third party holds your data.

    • Approve or reject an action over a spending limit
    • Complete a blocked step, such as an MFA code you permit
    • Other tasks keep running while one is parked
